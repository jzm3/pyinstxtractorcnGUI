逆向工程工具 Python 图形界面 与核心库同步更新

项目介绍

pyinstxtractorcnGUI 是开源 Python 库 pyinstxtractorcn 的官方图形界面版本。它将命令行操作转化为直观的点击操作，无需记忆复杂命令，即可轻松解包和分析 PyInstaller 生成的 Windows 可执行文件 (.exe)。

本项目将与核心库保持同步更新，为您提供持续稳定的服务。
